# TaskFlow — Task Manager

TaskFlow — веб-приложение для управления задачами.

## Возможности

- Создание задач
- Просмотр задач
- Редактирование задач
- Удаление задач
- Изменение статуса задачи
- Установка приоритета
- Установка даты выполнения
- Поиск задач
- Фильтрация задач
- Сортировка задач
- List и Board режимы
- Drag & Drop в Board режиме
- Обработка ошибок
- Проверка некорректных данных

## Технологии

### Frontend

- React
- Vite
- JavaScript
- CSS

### Backend

- Python
- FastAPI
- SQLAlchemy
- SQLite
